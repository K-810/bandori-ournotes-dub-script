# 03c · 称呼规律（怎么把 03b 读成规律）

> 03b 是**流水账**（谁怎么叫谁）；本页是**归纳**：每人属于哪一派，谁在什么时候换了叫法，
> 名字该写汉字还是假名，以及**名字之外的专属叫法**（绰号、片假名昵称——这一层名字扫描扫不出来）。
> 中→日时先看这一页定"派别"，再回 03b 查具体写法。
>
> 本页所有次数都由 `03b` 同一份统计导出（最长匹配 + 假名边界计数），**与 03b 数字一致**。

## 一、称呼风格分档（按派别，不按人）

| 派别 | 代表人物 | 中→日怎么写 |

## 二、称呼会随时间变的对（前段 ≠ 后段）

实测只有 5 对出现明显切换；**其余对全程不变**。

| 对 | 前段 | 后段 | 话次范围 | 说明 |
|---|---|---|---|---|
| 灯 → 爱音 | `愛音ちゃん`(25) | `あのちゃん`(23) | 10002–10686 | 分界约在 10017；**写早期场景要用 `愛音ちゃん`** |
| 爱音 → 灯 | `燈ちゃん`(54) | `ともりん`(64) | 10001–10680 | 从客气到熟络 |
| 心玖 → 蕾叶 | `蕾叶ちゃん`(28) | `蕾叶`(9) | 10083–10934 | 10098 之后转呼び捨て |
| 心玖 → 宁月 | `寧月ちゃん`(18) | `寧月`(24) | 10085–10934 | 同上 |
| 祥子 → 立希 | `立希さん`(4) | `立希`(4) | 10004–10033 | 次数少，**存疑**，用前回原文核 |

**用法**：写早期剧情时用"前段"那一列；写完检查有没有把晚期的叫法带到早期。
**反向也成立**：把早期叫法带到晚期，同样失真（灯在后期已经不叫 `愛音ちゃん` 了）。

**乃花的原话**（唯一一条"本人对叫法表态"的证据，可直接用来判断创作者的用法是否成立）：

```
adv_script_nonoka_miyako_linkstory_1#7
ノット『ののかさん』！　イエス『ののちゃん』！！
```

> 计数口径：本表次数取自 `03b` 同一份统计（`称呼表v4.tsv`）。
> 只有 `ののちゃんさん` 例外——它被最长匹配并进了 `ののちゃん`（32 次里含这 29 次，
> 剩下的 3 次是裸 `ののちゃん`），所以要单独数。

**若麦的成套片假名昵称**（她一个人对 Ave Mujica 全体用的，四条都是 100% 她独有）：

```
adv_script_mujica_002_1_03#88
てか、ウミコ一般人のくせに話題になってんのムカつく！
有名なウイコやムーコならわかるけど……
```

| 她叫 | 写成 | 来源 |
|---|---|---|
| 丰川祥子 | `サキコ` | さきこ 全名片假名化 |
| 若叶睦 | `ムーコ` | むつみ → ム＋ー＋コ |
| 八幡海铃 | `ウミコ` | うみり → ウミ＋コ |
| 三角初华 | `ウイコ` | ういか → ウイ＋コ |

**规则**：**这四条不能反推**。`ウミコ`／`ウイコ`／`ムーコ` 里没有目标名字的任何连续两字，
靠"名字变形"永远扫不出来——而中文原文里创作者如果写成「小海」「小初」，日语就该落成这两条。
她的昵称**只给同团人**；对 MyGO 成员她在这部语料里从不用名字称呼。

**三条注意**：

1. **片假名别写成罗马字**。语料里是 `さきちゃん`／`サキコ`／`りっきー`／`チェリ`，
   **没有出现过 `Tomorin`／`Rikki` 这类罗马字写法**（实测 0 次）——写进台词会突兀。
2. **绰号不等于一定可当面叫，但也不等于背后叫**。`野良猫` 是立希对乐奈用得最多的写法（43 次），
   **她是当面叫的**；`サキコ` 同理。别自己加"这是背后叫的"这类限制。
3. **敬称重ね是角色的标记**。`ののちゃんさん`、`ユノさんちゃん` 这类"ちゃん+さん"是原文真有的，
   碰到不要顺手改顺——改了就不是这个人了。

## 四、名字该写汉字还是假名（**中→日必查**）

日语里同一个人的名字可能有汉字、平假名、片假名三种写法，**选错就立刻露馅**。
以下为实测（"0 次"＝全语料 25,377 行里从未这样写过）：

| 角色 | 汉字写法 | 实际怎么写 | 证据 |
|---|---|---|---|
| 梅里千樱梨 | `千櫻梨` **0 次** | 自称 `ちえり`；队友 `チェリ` | 汉字写法从未出现，连自我介绍都用假名 |
| 宫永野乃花 | `野乃花` **0 次** | `ののちゃん`（自称与他人通用） | 125 次自称（119 行），全是 `ののちゃん` |
| 千石由乃 | `由乃` **0 次** | `ユノ`（片假名，全库 215 次） | 姓 `千石` 仍写汉字（41 次） |
| 祐天寺若麦 | `若麦` **0 次**、`わかば` **0 次** | `にゃむ`（87 次）／`にゃむち` | 姓 `祐天寺` 只在自我介绍时出现 |
| 丰川祥子（若麦口中） | `祥子` 0 次（她本人） | `サキコ`（片假名，32 次） | 别人写 `祥子`／`祥ちゃん` |

**规则**：**招牌写法只能照抄**。汉字名与假名名不是"正式/随便"的关系，
而是"这个人在剧里就是这么被写的"——创作者若用错，读起来便像换了个人。
判断方法：在 03b 里搜该角色，看**别人怎么写她**；再在 02 里看**她怎么写自己**。

## 五、怎么用这三页

```
① 看 03c 定派别       → 她是"さん 派"还是"呼び捨て派"
② 回 03b 查具体对     → 她对「那个人」到底怎么叫
③ 再看本节二的表       → 这一场是早期还是晚期，称呼要不要跟着变
④ 查本节三、四         → 有没有专属绰号；名字该写汉字还是假名
⑤ 都查不到            → 表里没这一对，说明原文没这么叫过（可提醒一句，见 03b 末尾）
```

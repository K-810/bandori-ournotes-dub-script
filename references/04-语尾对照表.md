# 04 · 语尾对照表（中 → 日，本技能的核心）

> 语尾是**听感上最直接的一层**：音色换对了但语尾错了，一听还是不像。
> 中→日的难点在这里：中文的「吧／呢／啊」粒度太粗，日语却有一整套终助词系统。
> 用法：左列从中文出发 → 中列给日语的候选 → 右列是哪些人用、以及易错点。

## 一、中文语气词 → 日语候选

| 中文 | 语境 | 日语候选 | 常用者 · 注意 |
|---|---|---|---|
| 「吧」 | 征求同意 | `〜でしょ` / `〜だよね` / `〜じゃん` | 前者中性、`じゃん` 是爱音语（z=7.0） |
| 「吧」 | 提议 | `〜ましょう` / `〜ようか` | 注意"我们"要不要加 |
| 「吧」 | 推测 | `〜かな` / `〜だろう` | `かな` 偏常体自问 |
| 「呢」 | 反问／追问 | `〜の？` / `〜んだけど？` / `〜のか？` | `の？` 女性向；`のか？` 偏硬 |
| 「呢」 | 说明 | `〜のよ` / `〜んです` | 祥子系：`のよ` 是她的标志 |
| 「啊」 | 感叹 | `〜なあ` / `〜わ` | `わ` 是**女性**终助词，别用在短句型角色上 |
| 「啊」 | 通知 | `〜よ` / `〜ね` | `よ` 告知、`ね` 求同 |
| 「吗」 | 一般疑问 | `〜？`（上升） / `〜の？` / `〜ですか` | 按敬体度选 |
| 「嘛」 | 口语断言＋求同 | `〜じゃん` / `〜だし` / `〜もん` | 爱音的 `じゃん`／`し` |
| 「啦」 | 俏皮收尾 | `〜っ`（促音） / `〜よ` | 阿拉蕾 `っ`、千樱梨 `っ` |
| 「哦」 | 提醒 | `〜よ` / `〜わよ` | 按角色选硬软；本企划不用 `〜ぞ`（见第六节） |
| 「呀」 | 轻快 | `〜や`（关西） / `〜だよ` | 关西腔只在角色设定如此时用 |
| 「而已／罢了」 | 限定 | `〜だけ` / `〜くらい` | — |
| 「来着」 | 回想 | `〜っけ` | — |
| 「算了」 | 放弃 | `〜やめとく` / `〜いいや` | 常体角色 |
| 「不行」 | 禁止 | `〜な` / `〜だめ` / `〜ちゃだめ` | 与感叹 `〜な` 同形，看语境 |
| 「求你」 | 请求 | `〜て` / `〜てよ` / `〜てくれない？` | 按敬体度与关系选 |

## 二、句末形态（比终助词更重的一层）

中文的语气也常由**句子结构**承担，日语要换成对应句式：

| 中文句式 | 日语 | 常用者 · 注意 |
|---|---|---|
| 「……的。」（说明） | `〜の` / `〜のよ` / `〜んだ` | 祥子、真白系 |
| 「……是……但」 | `〜けど` / `〜けれど` | **不能省**，省了就变强势 |
| 「……而且」 | `〜し` | 爱音 `し` z=5.9（话痨感来源） |
| 「好像……」 | `〜みたい` / `〜っぽい` | — |
| 「听说……」 | `〜らしい` / `〜って` | — |
| 「不小心……」 | `〜てしまった` / `〜ちゃった` | 口语 `ちゃった` |
| 「先……好」 | `〜ておく` / `〜とく` | — |
| 「不是……吗」 | `〜じゃない` / `〜じゃん` | 爽世 `じゃない` 21%★ |

## 三、性别语与角色色彩（选错即失真）

| 日语 | 色彩 | 谁用 | 别给谁 |
|---|---|---|---|
| `〜わ` / `〜わよ` / `〜わね` | 女性、明确 | 祥子、Oblivionis | 中性、短句型角色 |
| `〜のよ` / `〜のね` | 女性、说明 | 祥子系 | 敬体率 0% 的短句型角色 |
| `〜ですわ` / `〜ますわ` | 极优雅敬体 | 祥子、Oblivionis | 其他任何人 |
| `〜じゃん` / `〜っしょ` | 若者、口语 | 爱音系 | 敬体角色 |
| `〜っ`（促音收尾） | 俏皮、跳 | 阿拉蕾、千樱梨 | 沉稳角色 |
| `〜かしら` | 女性、略年长 | 慎用 | 十几岁角色用会显老 |
| `〜だい` | 略旧式、偏年长的疑问 | 蕾叶、祥子**都在用** | 不要当"男性语"处理 |
| `〜だろ` / `〜だな` | 常体推量／感叹 | 宁月、萤、爽世、爱音**都在用** | 同上，不是男性专属 |

> **本企划真人配音里没有男性角色**——所以本表**不列男性专用语尾**。
> 语料实测：`〜だぞ` 全库 **11 次**、`〜だぜ` **9 次**、`〜やめろ` 5 次，
> 且几乎都在旁白或路人台词里。**不要给主要角色用，也不要把她们写成"像男生说话"。**

## 五、两条最实用的判断

1. **看句长**。日语句长与中文可以近似对应：
   乐奈 6 字、睦 10 字、灯 11 字 → **中文的长句必须砍短**；
   蓬咲 28 字、千樱梨 28 字、朋花 24 字 → **别缩成一短句**。
   ★ 句长是最容易被忽略、又最影响"像不像"的一项。
2. **语尾不许静默消失**。译完数一遍：中文每个语气词，日文里是否都有对应物
   （终助词、句末形态、标点、句长）。**找不到的要么补，要么标「需判」。**

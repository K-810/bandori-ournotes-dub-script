# 09 · 语体基线（机器可读）

> **给 `vtool audit` 取基线用。** 手上拿到一份日文稿时，先跑：
>
> ```bash
> node tools/vtool.mjs audit 稿子.txt [--src 中文原文.txt]
> ```
>
> 它按本表比对每个说话人的**敬体率 / 句长 / 自称 / 句尾多样性**，另查全篇的「あなた 密度」
> 与「中日逐句长度是否等比」。**形式不对基本可以确定没逐句想过；形式对了也不代表想过**
> ——后半句只能靠抽查（见 `06` 第十三节）。

## 口径

| 列 | 定义 |
|---|---|
| **主自称** | 该角色出现最多的第一人称。**名字自称**（`ののちゃん`／`ちえり`／`にゃむ` 直播口吻）算自称，见 `02` 第六节。占比低是常态——多数句子里自称不出现 |
| **敬体率** | **一次发言里出现 `です・ます` 类的比例**（含句中）。⚠️ 不是只数句末：只数句末会低 2–3 倍（祥子 18% vs 51%）。与 `05` 第五节同口径 |
| **句长** | 该角色台词的平均字符数（不含空白与换行，含标点）。全量口径 |

数值由语料算出。`02`／`04`／`05` 是给人的说明，本表是给脚本的；两处若有 1–2 个百分点的出入，
**以本表为准**（本表与 `audit` 用同一段代码、同一口径）。

## 用法（audit 怎么判）

| 检查 | 提示线 | 说明 |
|---|---|---|
| 敬体率 | ±15 个百分点 | 越线先查 `05` 第五节，别凭中文的「您／请」反推 |
| 句长 | ±40% | 短句型角色（灯／睦／乐奈）超了要砍句；长句型（蓬咲／千樱梨／朋花）缩了要补 |
| 自称 | 用错**专属**自称 | `わたくし`→祥子系 · `アタシ`→若麦系 · `ぼく`→阿拉蕾 · `僕`→灯／初华台上 · `俺`→蓬咲 |
| 句尾多样性 | 话多的角色只剩 1–2 种收尾 | 逐句套模板的形状，人写会自然散开 |
| `あなた` 密度 | 全篇 >5% | 熟人之间默认用名字或省略，见 `03d` |
| 中日逐句长度 | 行数一致且长度比变异系数 <0.18 | 人做会拆句合句、长短不齐；等比是逐句直译的形状 |

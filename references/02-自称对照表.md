# 02 · 自称对照表（中 → 日）

> 中文只有「我」，日语有十几种——**这是中→日最容易走形的一层**。
> 下表先给「怎么选」，再给 30 人的实测分布（来源：日文语料统计）。

## 一、怎么选（中文「我」→ 日语自称）

| 日文自称 | 气质 | 什么角色／场合用 | 别用 |
|---|---|---|---|
| `わたくし` | 极正式、名门／营业腔 | 台上代号（Oblivionis）、正式致辞、名门小姐 | 日常场合、亲近对象 |
| `わたし` | 中性、偏正式 | 成年女性、服务场合、初次见面 | 与同伴打闹时 |
| `私`（わたし／あたし） | 最常见、中性 | 多数角色的默认 | 一律用它区分不了人 |
| `あたし` | 女性口语、明快 | 心、枣、心玖、由乃这类活泼型 | 摆架子时 |
| `アタシ`（片假名） | 强调、张扬 | 若麦、Amoris | 收敛场合 |
| `うち` | 关西／少女口语、亲昵 | **本作里没人当主自称**（各角色都 <1%）；偶发用 | 正式场合 |
| `僕` | 少年感、谦和／台上用 | 阿拉蕾；Doloris（★与台下初华的 `私` 不同） | 已定「あたし」的角色 |
| `俺` | 粗放、自信 | 蓬咲偶尔、Amoris 偶尔（占比很低） | 通篇用（会过火） |
| `自分` | 体育系／谦抑，或反身强调 | **本作里也几乎没人用**（最多的是马桥心玖 15 次） | 普通对白（听着像在念报告） |

**两条判断**：
1. **先查角色档的实测占比**（下表），占比最高的那个就是她的默认自称；
2. **中文句子里没有主语时，多数情况日语也不必补**——补了要多一次"选词"，多一次走形机会。
   尤其乐奈、睦、灯这类短句型角色。

## 六、用名字自称（**比自称代词更醒目的一层**）

日语里有一类人不說「私」，而是**用自己的名字当主语**（「〇〇はね」「〇〇です！」）。
中文原文里往往只写「我」，翻成 `私` 就把这个人最鲜明的标记抹掉了。实测有三个人是这种：

| 角色 | 名字自称 | 实测 | 写法 |
|---|---|---|---|
| 梅里千樱梨 `chieri` | `ちえり` | **325 次**（301 行 / 全 704 行 = **42.8%**） | `ちえりはすごいんですよ！` / `このちえりが` / `ちえりのために` |
| 宫永野乃花 `nonoka` | `ののちゃん` | **125 次**（119 行 / 948 行 = **12.6%**） | `ののちゃん５歳！` / `ののちゃんもだっこしたーい！` |
| 祐天寺若麦 `nyamu` | `にゃむ`（21 次）· `にゃむち`（10 次） | 31 次 | `にゃむちのメイク動画、新しいの配信されたんだ`（直播口吻） |

> 口径：**出现次数**（不是行数）；被同族更长写法包住的那一截不重复数（`にゃむ` 不数 `にゃむち` 里的）。
> 有 `vtool` 时用 `self <角色>` 直接看这一层。

**另外四人只在自我介绍时用名字**（**不要推广到日常台词**）：
爱音 `千早愛音です！`（10 次）、祥子 `わたくし、豊川祥子と申します`（20 次，且同时用了 `わたくし`）、
蓬咲 9 次、蕾叶 6 次、阿拉蕾 6 次。
**区别在于：前者是日常主语，后者只是报名字。**

**规则**：查到这类角色时，把中文的「我」**优先落到名字上**——这是她的语体，不是口误。
千樱梨尤其要注意：语料里她的名字**从未写成汉字 `千櫻梨`**（0 次），
自称一律 `ちえり`（详见 03c 第四节）。

## 七、两个统计陷阱（用数字前必读）

1. **同一角色跨作品会变**：祥子的 `わたくし` 在另一部作品里查不到。
   → **按作品分别建档**，不要跨作品套用。
2. **片假名要单独数**：`アタシ`／`ワタシ` 与 `私` 不是一回事，漏了会低估这层标记
   （六节的片假名名字同理：`ユノ`／`チェリ` 都算"名字"，不算外来语词汇）。

## 八、禁止事项

- ❌ 为了区分角色，给每个人硬配一个不同的自称（真人说话没这么刻意）。
- ❌ 中文没主语的地方硬补「私」——**日语省主语也是常态**，补多了反而像在念稿。
- ❌ 把「私」的数量当性格：话多的人自称出现多，只是因为句子多。
- ❌ 把六节的名字自称"改顺"成 `私`——那正是这个角色被认出来的地方。

## 九、台上代号：**演出来的那一版**（成套切换）

Ave Mujica 上台用代号（Oblivionis 等）。**那是同一个人按台上设定"演"出来的一版语体**——
不是日常说话的样子，所以处理方式是：**台词在台上时，四层一起换；下了台立刻换回来。**

| 台下 → 台上 | 变化方向 |
|---|---|
| `sakiko` → `oblivionis` | `私` → `わたくし`；常体 → 敬体；句尾更硬 |
| `uika` → `doloris` | `私` → `僕`；句长变短、语气变直 |
| `umiri` → `timoris` | 敬体度略降；句尾由 `すね` 转为收敛 |
| `nyamu` → `amoris` | 张扬度再上一档；`アタシ` 占比升高 |

**切换时四层一起换**：自称、语尾、敬体度、句长。
**只换一个词、其余照旧，是最容易读出来的破绽**；反过来，台上腔带下台也是。

## 十、说话人 id 的写法（数据层）

> 本节只在你**自己取数**时有用（数据包见 07）；纯写作时可以跳过。

语料里的说话人 id 是脚本用的编号，写法有规律，**不必逐条去猜**：

| 写法 | 含义 |
|---|---|
| `sakiko` / `hotaru` | 该角色的**素の语体**（日常、台下） |
| `oblivionis` / `doloris` … | 同一角色**台上代号**的那一版（见第九节） |
| `hotaru_child` / `miku_child` | 同一角色的**幼少期**版本（语体更幼） |
| `hotarumother` / `nyamumother` | 亲属角色，不是该角色本人 |
| `classmatea` / `audiencea` / `seitoa` … | 无名路人，占 402 个说话人里的大多数 |

**只处理你需要的**：主角与主要配角；`*_child` 可按需，路人不建语体档。

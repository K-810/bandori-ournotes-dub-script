## 给 TTS 的注音

交付 GPT-SoVITS 这类日语 TTS 时，**除了台词稿再给一份注音稿**——
日语前端靠词典猜汉字，`豊川` 会读成 とよかわ（正确 とがわ）。

- **注音表（25 人官方读法＋绰号）与做法写在 `SKILL.md` 根层级的「给 GPT-SoVITS 的注音稿」一节**；
- 生成：`node tools/vtool.mjs read`（看表）／`read --in 稿.txt`（批量出注音稿），**不需要语料包**。

## 拿不准日语怎么说时

**别逐字翻中文，去查"这个场合日语怎么说"。** 两个来源：

- `04` 的表格本身就是一本**说法词表**：什么语气 → 哪个终助词；
- `05` 给的是**场合词表**：道谢、道歉、请求、谦让各说什么，以及授受方向怎么落。

这比"把中文词换成日语词"可靠得多——前者是在**选说法**，后者是在**造怪句**。

## 取用时注意

- 本技能给的是**语体**（怎么说话），不是**人设**（是什么样的人）。
- 数字来自日文语料统计；**同一角色跨作品会变**（例：祥子在不同作品里的自称不同），逐作品核对。
- 三条硬约束：中文原文是内容不许改、不比较角色价值、不对外解释资料范围。

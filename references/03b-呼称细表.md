# 03b · 呼称细表（谁怎么称呼谁）

> 全语料（955 集、25,377 行）扫出的**实际称呼**，按「说话人 → 对象」列，**按出现次数降序**。
> **两种用法**：① 查该说话人对该对象平时怎么叫；② **失配检查**——作者写的称呼不在这张表里，说明原文没这么叫过。

**读法**：`写法(次数)`，★ 是该对里最多的；**话次区间**数值越大＝越靠后。

**计数规则**（这一版修掉了旧版三处毛病）

1. **最长匹配优先**：`ともりん` 不再被算成 `ともり`；`心玖ちゃん` 不再被算成 `心玖`＋`心玖ちゃん` 各一次。
2. **纯假名写法要过边界**：`らな` 不再命中 `なら`／`〜からな`（旧版十来个说话人莫名其妙会叫乐奈，就是这么来的）。
3. **绰号与名字同级**：`ともりん` `そよりん` `りっきー` `あのちゃん` `サキコ` `チェリ` `野良猫` 与名字一起参与匹配。
4. **自称不计**：`ちえり` 在自己嘴里出现 300 次，那是自称，不算呼称（自称见 02）。

**三条边界**

1. **低频不等于错**：次数少说明原文里很少这么叫，作者要用是他的自由；
2. **只统计"说出口的称呼"**：日语大量场合**直接省略称呼**，省略同样正确；
3. **表里没有这一对 = 原文没这么叫过**——这才是失配检查的依据。

## 失配检查：怎么用

```
作者写：立希对爱音说「愛音さん、お疲れ」
查表：立希 → 爱音 只有 愛音(17)，从来没有 愛音さん
做法：不算错，可以在对话里问一句——
      「她对爱音一直是直接叫名字，加さん会显得生分。你要的是这个效果，还是改成 愛音？」
```

**三条纪律**：① 只在"表里有这一对、且从不用该写法"时才提，**表里没有这一对就不提**；
② 说成"原文里没这么叫过"，不说"你错了"，一次只提一处；③ 改不改由作者定。

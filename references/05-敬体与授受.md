# 05 · 敬体与授受（中 → 日）

> 敬体（です・ます）决定「端着还是松开」；授受补助动词决定「谁欠谁」。
> 中文两者都没有语法位——**所以中→日时它们是"必须补"的两层**，也是最容易漏的两层。

## 一、敬体度：**不许从中文反推**

先记住这条：**中文有没有「您／请」不能决定日语的敬体度。**

| 中文表现 | 日语的敬体度（正确来源） |
|---|---|
| 用了「您／请／麻烦」 | 可能是敬体，**也可能是阴阳怪气或客套疏远** → 看角色档 |
| 通篇「你」 | 可能是常体，**也可能照样是敬体**（日语敬体与二人称无关） |
| 没有礼貌词 | 看**场合**：对生人、对上级、公开致谢 → 仍可能是敬体 |

**唯一依据**：① 角色语体档（恒定量）＋ ② 这一场的场合（变量）。

### 三档落地

| 档 | 句末敬体率 | 代表 | 中→日怎么写 |
|---|---|---|---|
| **全程常体** | 0–10% | 乐奈 0 · 由乃 0.4 · 枣 0.6 · 立希 1.5 · 爽世 1.7 · 宁月 1.7 · 初华 1.9 · 灯 2.0 | **一个 です・ます 都不许有**；句尾用 `だ／よ／ね／じゃん／の`（按人） |
| **混合** | 20–65% | 萤 29.2 · 律 30.8 · 都子 39 · 蓬咲 46 · 祥子 50.2 · 海铃 64.8 | **按对象开关**；同一篇里要能看出开关（对同伴常体、对生人敬体） |
| **全程敬体** | 70%+ | 朋花 71 · 千樱梨 80.8 | 通篇です・ます；不用「〜だよ」这类常体收尾 |

> ⚠️ **口径**：这里的「敬体率」＝**句末**为です・ます 类的比例。另有"句中出现"的算法会高近一倍，**别混用**。

## 二、谦让语与尊敬语：中文给不了，得按关系加

| 场合 | 日语要加什么 | 例 |
|---|---|---|
| 压低自己 | 谦让：`させていただく`／`いたす`／`〜ております` | 「我来做」→ 由我来做 → `私がいたします` |
| 抬高对方 | 尊敬：`いらっしゃる`／`おっしゃる`／`〜なさる` | 「您来」→ `いらっしゃる` |
| 郑重 | `ございます`／`でございます` | 服务、名门、正式致辞 |
| 亲近（反方向） | 常体 + 终助词 | 同辈、队友、幼驯染 |

**判断口诀**：先定关系（上下／内外／亲疏），再定敬体，最后才挑词。
中文这里什么都不给，**全靠角色档 + 关系表**。

## 三、授受补助：中文的「给／帮／替」要翻成结构

| 中文 | 日语的正确形态 | 易错 |
|---|---|---|
| 「我帮你……」 | `〜てあげる`（亲近）／`〜てさしあげる`（谦让，慎用） | 对上级用 `あげる` 会失礼 |
| 「（他）帮我……」 | `〜てくれる`／`〜てくださる`（尊敬） | 写成受身 `〜られる` 就丢了恩惠方向 |
| 「我请他……」 | `〜てもらう`／`〜ていただく` | 漏了"请"就变命令 |
| 「能不能帮我……？」 | `〜てくれない？`／`〜てもらえる？`／`〜ていただけますか` | 按敬体度选；常体角色用最高级敬语会走形 |
| 「我给你……」 | `〜てやる`（下对上或粗）／`〜てあげる` | `やる` 用错场合会显得傲慢 |

**检查法**：写完日文，回头看中文——**凡是中文有"帮／替／给／请"的地方，日文里必须有对应的授受补助**。

## 四、黏着叠加：一层层挂上去

中文一句话，日语可能是「使役＋授受＋敬体＋终助词」四层。挂的顺序：

```
动词 → 使役/被动 → 授受 → 敬体 → 终助词
```

| 中文 | 日语 |
|---|---|
| 「请您让我退出」 | `やめさせていただけますか` |
| 「他逼我吃的」 | `食べさせられた` |
| 「能让我看一下吗」 | `見せてもらえますか` |
| 「（你）能来真好」 | `来てくれてよかった` |

**口诀**：**先挂恩惠方向（授受），再挂使役被动，最后上敬体与终助词。** 顺序反了句子会绕。

## 六、两个常见翻车

1. **敬体整套漂移**：写长稿时前面对、后面对不上。→ 把语体档**贴在稿头**，每章校对一次。
2. **拿「请」当万能钥匙**：中文一个「请」，日语却有 `ください／お願いします／いただけますか／どうぞ` 之别，
   按敬体度与场合选错就出戏。

# 07 · 取数说明（怎么拿到「她平时是怎么说的」的证据）

> 本技能**不含剧情原文**（版权原因）。需要日语语料做取证时，按本文件自备。
> 没有语料也能用——`02`–`05` 的对照表与实测数字就是最低可用集。

## 一、语料要什么样的

| 项 | 要求 |
|---|---|
| 内容 | **日文原文** + 说话人 + 集号；有官方中译更好，但**本技能不依赖它** |
| 粒度 | 一句一行、可定位（`<集资产名>#<行号>`） |
| 编码 | UTF-8 |
| 来源 | 官方文本（游戏剧情脚本）。避免机器翻译、残缺拼接版本 |

**格式示例**（制表符分隔，一行一句）：

```
asset	idx	speaker	jp	zh
adv_script_millsage_004_1_07	12	hotaru	私、この曲が好きです	我很喜欢这首歌
```

## 二、放哪

放**任意位置**即可，**不要放进技能目录**——技能升级会整体覆盖。
记下路径，用下面的方式告诉 AI。

## 三、怎么用（三档，按环境选）

| 档 | 环境 | 怎么做 |
|---|---|---|
| **A** | 只有对话窗 | 直接用 `02`–`05` 的对照表。要例句时，把想到的日语说法在对话里问一遍 |
| **B** | 能贴长文本 | 把相关**那一集**贴进来，让 AI 在里面找同类语尾的用法 |
| **C** | 有文件系统、能跑 Node | 用 `tools/vtool.mjs`（见下） |

## 四、`vtool.mjs`（C 档）

零依赖，只用 Node 内置模块。**脚本里不含任何数据**：

```bash
node vtool.mjs --pack <语料目录> self  hotaru
node vtool.mjs --pack <语料目录> tail  sakiko わ
node vtool.mjs --pack <语料目录> call  anon
node vtool.mjs --pack <语料目录> map   sakiko
node vtool.mjs --pack <语料目录> line  adv_script_millsage_004_1_07#12
node vtool.mjs model <Live2D 模型目录>
node vtool.mjs read                                  # 注音表（不需要语料包）
node vtool.mjs read --in 稿.txt --out 稿_注音.txt      # 出注音稿（不需要语料包）
node vtool.mjs audit 稿.txt --src 中文原文.txt          # 稿子体检（不需要语料包）
```

| 子命令 | 输出 | 中→日时拿它干什么 |
|---|---|---|
| `self <角色>` | 语言指纹：自称分布 · 敬体率 · 语尾 top10 · 平均句长 | ★ 建角色语体档（第一步）就是照这个填 |
| `tail <角色> [语尾]` | 该语尾的**真实例句**，日文 + 出处 | 想确认「她这个语尾是怎么用的」时看实例 |
| `call <角色> [对象]` | 称呼取证：`さん／ちゃん／先輩／呼び捨て` 各多少 | 决定这句该叫名字还是加さん |
| `map [角色]` | 「日文写法 → 中文名」对照表（自动学出） | 查绰号（如 `サキコ` 指祥子） |
| `model <模型目录>` | 该 Live2D 模型可用的表情/动作名 | WebGAL 侧用（见 `08`） |
| `line <集>#<行>` | 定位一句，带前后文 | 核对上下文 |
| `exp <集号> [角色]` | 该集的表情/动作码 | 只在需要游戏原生演出时用 |
| `read` | **注音表**（26 人官方读法＋绰号），可对稿子批量出注音稿 | 交付给 GPT-SoVITS 时用（见 `SKILL.md`） |
| `audit <稿> [--src <中文>]` | 稿子体检：敬体率／句长／自称／句尾多样性／直译形状 | ★ 交稿前必跑（`06` 第十三节）；基线读 `09` |

**角色参数**：说话人 id（`hotaru`）或中文名（`汐见萤`）都可以；简称（`萤`／`祥子`）也认。

**敬体率口径**：`self` 与 `audit` 都按「**一次发言里出现 `です・ます` 类的比例**」算（含句中），
与 `05` 第五节、`09` 一致。**不是只数句末**——只数句末会低 2–3 倍。

**输出默认只有日文**；要中日对照加 `--cn`。默认只列 10 条，用 `--limit` 调整。

### `map` 与 `call` 的已知局限

名表是**从双语对齐自动学出来的**（某行中译里出现角色 X 的中文名 → 该行日文里的候选写法即 X 的日文名）。
好处是不用维护、假名绰号也能收进来。局限：**用姓称呼的人**可能被并到同姓的其他角色名下。

→ 遇到可疑归属：用 `map` 看全表，或**直接以原文为准**。

## 五、没有 Node 怎么办

按 **B 档**走，并让 AI 用等价的手工问法：

> 「这是第 N 集的日文台词。请找出其中所有以 `〜わ` 结尾的句子，按角色分组，并说明各角色用了多少句。」

## 六、别做的事

- ❌ 把官方中译当"正确答案"去校验日语——**中→日方向的真源是角色语体档**，不是官方中译。
- ❌ 拿**别的作品**的语料套本技能的角色档（同一角色跨作品自称会变，见 `02-自称对照表.md`）。

## 七、本技能里的数字是怎么来的（可复现）

`02`–`04` 的实测数字、"派对别"与 `03b` 的全部次数，都来自**同一份统计**，规则如下。
你自己有一份日语语料时，照这四条重算，结果应当一致。

### 7.1 称呼计数（`03b` 的口径）

| 规则 | 为什么 |
|---|---|
| **最长匹配优先** | `ともりん` 不许被同时算成 `ともり` + `ともりん`；`心玖ちゃん` 同理 |
| **纯平假名写法要过边界** | 否则 `らな` 会命中 `やらない`／`〜からな`，凭空长出十来个"叫乐奈"的说话人 |
| **绰号与名字同级参与匹配** | `ともりん` `そよりん` `りっきー` `あのちゃん` `サキコ` `チェリ` `野良猫` 都是称呼 |
| **自称不计入呼称** | 千樱梨的 `ちえり` 有 325 次（301 行），那是自称（进 `02`），不是别人叫她 |

带敬称的写法（`そよさん`）右边界由敬称自己保证，不必再挡；片假名串（`サキコ`／`チェリ`）与
多字汉字名也不会被同形词拆开，一律免检。

### 7.2 挖"个人习惯"（`03c` 的绰号与表记形态是这么找出来的）

不要去猜昵称的构词法（猜不全），**反过来做**：

1. 把语料里所有 **2–6 字的连续假名/汉字片段**切出来；
2. 统计每个片段**被哪个说话人用了多少次**，算"集中度"（该说话人次数 ÷ 全库次数）；
3. **集中度 ≥ 0.6 且次数 ≥ 4** 的片段，就是那个人的习惯表记；
4. 再按"有没有接敬称、是不是在呼格位置（后接敬称／标点）"分类，去掉同形常用词
   （`ほう`、`いか`、`のか`、`だろうか` 这类要靠"全库是否常接敬称"挡）。

这一套一次就捞出了：`チェリ`（家团对千樱梨）、`あのちゃん`（灯对爱音）、
`りっちゃん`（两人对律）、`ののちゃんさん`（阿拉蕾对乃花的敬称重ね），
以及**三个人用名字自称**（`ちえり` 325 · `ののちゃん` 125 · `にゃむ`+`にゃむち` 31）。

#### 7.2.1 第二条通道：**独用片假名串**（7.2 的补充，缺了会漏掉一整类）

7.2 只认「含目标名字 2-gram 的片段」，**对纯片假名化昵称无效**：
若麦叫海铃 `ウミコ`、叫初华 `ウイコ`、叫睦 `ムーコ`——这三串里没有目标名字的任何连续两字。
所以再加一条通道：

1. 把全语料里所有 **2–6 字片假名串**切出来；
2. 每个串算「集中在哪个说话人身上」；
3. **≥3 次、集中度 ≥0.6、且说话人在角色表内** → 输出候选，人工过一眼。

判定要点：**两个说话人都用的不是专属叫法**；真正专属的（若麦那四条）集中度都是 **1.00**。

> 这个通道还会捞出一堆非人名（`アタシ`、`ファミリー`、`ポケモン` 之类），
> 所以它的输出**必须人工筛**，不能直接进表。判定顺序：先看集中度，再看例句里是不是在叫人。

> 同一个方法换到**自称**一侧（片段出现在说话人自己的台词里），就是 `02` 第六节的来源。
> 关键提醒：**代词统计看不见名字自称**——只看 `私`／`自分`，会把千樱梨和乃花写错
> （千樱梨的 `自分` 只有 3 次，`ちえり` 有 325 次；乃花的 `うち` 只有 5 次，`ののちゃん` 有 125 次）。
> 自称一侧的边界规则要比呼称松：`このちえりが` 这种前接假名的写法也算，只去掉被更长写法包住的（`にゃむ` 不数 `にゃむち`）。

### 7.3 数"对不熟的人怎么叫"（03d 的来源）

熟人对熟人的称呼，看 `03b`；**对生人/半熟的人怎么叫**，要换两个量：

1. **二人称代词**：数每个角色的 `あなた／あんた／アンタ／君／お前／そっち`。
   代词是"关系的刻度"——对熟人一般直接叫名字，对生人才用代词（例：若麦是全语料 `アンタ` 的主要使用者，59/65）。
2. **对"不在角色表里的人"用的敬称**：把 `姓+さん／先輩／先生／様` 里**姓不在角色表**的那些单独数，
   那部分就是她对路人（店员、老师、工作人员）的习惯；再补上跨团对象的称呼（团外＝不熟）。

两条合起来才是完整的"生疏档"，见 `03d-生疏对象倾向表.md`。

### 7.4 每条结论都要能数出来

写进 `02`–`04` 的每一条，都要能回答"多少次、出自哪一集"。
本技能的实测数字都附了次数；**改动这些数字时，必须同时给出取数口径**，
否则下一轮复核无法判断是数据变了还是口径变了。

### 7.4 语料规模（供对照）

本文所述统计基于 **955 集 / 25,377 行 / 402 个说话人**的日语剧情脚本。
语料规模不同，次数会不同（尤其低频写法），**占比比次数稳**，跨语料比较请用占比。

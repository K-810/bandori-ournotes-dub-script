# 06 · 自检清单（中 → 日）

> 交付前过一遍。时间不够时，**至少跑 ① 与 ②**。

## ① 遮名测试（最重要）

**做法**：把日文的说话人名字遮住，交给没有上下文的人（或另一个模型）猜是谁。

**通过线**：主要角色**能猜对**；猜错等于语体没落地。

**快速版**（自己就能做）：把同一句中文用两个角色的语体各写一遍，看是否**读得出差别**。
读不出 = 两人的语体没分开 = 回改。

## ② 敬体一致性（中→日特有的检查）

逐句核对句末敬体：

- [ ] **0% 档的角色**：全篇没有出现 `です・ます`？
- [ ] **80% 档的角色**：没有出现 `〜だよ`／`〜じゃん` 这类常体收尾？
- [ ] **混合档的角色**：对同伴与对生人的开关**看得出来**？

> 中文原文在这件事上帮不了你，所以必须**专门查一遍**。

## ③ 缺项五问（每句都过）

中文里没写、日语必须写的五类：

- [ ] ① **自称**：该不该出现？出现的是不是她那一款（私／僕／あたし／わたくし）？
- [ ] ② **称呼**：日语有没有把「你」处理成名字／さん／ちゃん／省略？
- [ ] ③ **敬体度**：与角色档一致？
- [ ] ④ **语尾**：中文的「吧／呢／啊」有没有在日语里找到对应物（终助词或句法）？
- [ ] ⑤ **授受**：中文的「帮／替／给／请」有没有落成 `〜てくれる／あげる／もらう`？

## ④ 语尾清点

数一遍：中文里每个语气词，日文里是否都有对应物？
对应物可以是终助词、句末形态（`〜のよ`／`〜んだけど`）、标点（`〜`、`？`）、句长。

**找不到对应物的，要么补，要么去问作者（见 `01` 第五节）。** 不允许静默消失；
也不要把「需判」写进交付物——交付物里只有日文台词。

## ⑤ 句长对照

日语的音节数要跟角色的说话节奏对得上：

- 乐奈 6 字、睦 10 字、灯 11 字 → 中文的长句要**砍短、断句**；
- 蓬咲 28 字、千樱梨 28 字、朋花 24 字 → **不许缩成一短句**。

中文比原文长一倍或短一半，通常就是语体走形了。

## ⑥ 留白与沉默

- [ ] 中文原文是「……」的，日文也是「……」，没有替角色补台词？
- [ ] 该沉默的地方没有塞进终助词？（补语气补过头比漏掉更像"另一个人"）

## ⑦ 台上/台下（Ave Mujica 代号）

若文本里出现 Oblivionis / Doloris / Timoris / Amoris 这类台上代号：
- [ ] 四层（自称、语尾、敬体、句长）**一起**换了？
- [ ] 有没有残留台下的称呼？
- [ ] 下了台的地方，有没有把台上腔带回来？

## ⑧ 三条硬约束（行政检查）

- [ ] 中文原句**一字未改**（只改了日语表达）？
- [ ] 有没有写出「谁比谁强／谁拖累谁」这类比较？（有就删）
- [ ] 关键动作的归属是否与原文一致？（功劳落在做那件事的人身上）

## ⑨ 可核查性（新增：本表里每条"标志性说法"都要能对上原文）

- [ ] 引用了 `03-呼称对照表.md` 里某条**标志性称呼**时，是否确认过它在原文里真的存在？
- [ ] 引用了某条**语尾**时，是否确认过该角色真的常用它（`04` 的数字或自己跑 `vtool tail`）？
- [ ] **时间层**：这条特征是不是只在某一段剧情里成立？若是，晚期场景不要用。

> 教训：`03` 曾把「立希对爱音用 `あの野郎` 一类」写成她的标志——**核查后不成立**：
> 她对爱音始终是呼び捨て `愛音`，早期只是加了训斥语气。**没核过的特征宁可删掉。**

## ⑩ 中文的坑（Ctrl+F 一遍）

| 不该出现 | 为什么 |
|---|---|
| 直译中文成语／网络语 | 日语里会变成怪句 |
| 中文有「帮／替／给」而日文没有授受补助 | 恩惠方向丢了 |
| 中文是短句、日文写成长句 | 节奏不对，配音也念不出 |
| 每句都加「〜ね／〜よ」 | 语气词密度过高，会比原文浮 |
| 对上级用 `〜てあげる` | 失礼 |
| 中文的「你」一律落成 `あなた` | 熟人之间反而生分；默认应是名字或省略（`03d`） |
| 对生人硬造称呼 | 日语用「役割＋さん」（`店員さん`）或干脆不称呼 |

## ⑪ 生疏档检查（**新增**：对不熟的人最容易穿帮）

- [ ] 这一场她面对的是 **熟 / 半熟 / 生**？查 `03d` 定了档没有？
- [ ] **代词**：补之前查过 `03d` 第二节吗（多数角色一年也说不了几次二人称代词）？
- [ ] **称呼**：对生人有没有用「役割＋さん」或省略，而不是自造一个名字+さん？
- [ ] **升档整句升**：称呼、代词、句尾敬体是一起换的吗（只换一个词＝半吊子敬语）？
- [ ] **派别不随关系变**：呼び捨て派（立希／千樱梨／宁月…）跨团也照样呼び捨て，别顺手加さん。

## ⑫ 交付格式

- [ ] 只有日文台词，`说话人：日语` 一行一句？
- [ ] **没有**中文对照、**没有**注释、**没有**表情/动作/语音提示？
- [ ] 说话人写法与作者的剧本一致（中文名或 id）？
- [ ] 拿不准的地方，是在**对话里**问的，而不是写在稿子里？

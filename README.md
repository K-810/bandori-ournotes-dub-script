# bandori-ournotes-dub-script

《BanG Dream!》二创辅助工具。把**中文台词**落成「这个角色会这么说」的**日文配音台本**，
并给出配音用的**名字注音稿**。

覆盖 MyGO!!!!!、Ave Mujica、梦限大MewType、millsage、一家Dumb Rock!（家团）五团 25 人。

安装后，可向它提出以下问题：

- 祥子这句中文，日文该用 `わたくし` 还是 `私`？
- 爱音叫灯是 `ともりん` 还是 `燈ちゃん`？——这一场是早期还是后期？
- 若麦会怎么叫海铃？她要叫「小海」的话，日文是什么？
- 这句台词给海铃，她会不会转敬体？
- 把这段中文台词出成日文配音稿，再给一份 TTS 能正确读音的注音稿。

## 它解决什么问题

日语是黏着语，**人格长在语法里**。中文没有这些语法位置，所以中→日的难点不是词汇，
而是「中文没写的，日语必须补出来；补错了，人物就走形」。

| 日语必须补的位置 | 中文为什么给不了 |
|---|---|
| **自称**（私／僕／あたし／うち／わたくし） | 中文只有「我」，且常省略主语 |
| **二人称与呼称**（さん／ちゃん／呼び捨て／あだ名） | 中文「你」无差别，称呼常省略 |
| **语尾终助词**（わ／のよ／じゃん／っしょ） | 中文「吧／呢／啊」粒度太粗 |
| **敬体 vs 常体**（です・ます vs だ） | 中文动词不变化，不能由「您」反推 |
| **授受补助**（〜てくれる／もらう／あげる） | 中文「给／帮／替」常省略 |

同一句话，中文可以一模一样，日语却必须按人换一套：

| 中文（同一句） | 落成灯 | 落成若麦 |
|---|---|---|
| 「知道了，我去看看」 | `……わかった` | `オッケー、行ってみるわ〜` |

（这是原理示例，不是语料引用。）通用翻译求「像日语」，本技能求「像她」。

## 管什么 / 不管什么

| 管 | 不管 |
|---|---|
| 中文台词 → 日文台词的**说话方式** | 角色的**人设与剧情**（一设或者二设） |
| 自称、呼称、语尾、敬体、授受怎么落 | WebGAL 的**演出与表情建议**（只在与模型对不上时给判据） |
| 谁怎么称呼谁、什么时候换了叫法 | 把**官方中译**当标准答案（它会抹平语体） |
| 配音稿 / TTS 注音稿 | 替你改中文原文的内容 |

## 交付物

**一份日文台词稿**（纯日文，不夹注、不给表情与语音提示——夹注会被念进去）：

```
乐奈：バンド、やる？
爱音：え、なにそれ、めっちゃいいじゃん！
灯：……うん
```

**需要时再给一份注音稿**（只改名字写法，台词内容与标点一字不动）：

```
台词稿：祥子：豊川さん、三角さんと八幡さんも呼ぶ？
注音稿：祥子：とがわさん、みすみさんとやはたさんも呼ぶ？
```

说话人标记（`祥子：`）保留原样不替换，那是给作者看的，不进 TTS。

## 给 GPT-SoVITS 的注音

日语 TTS 的前端**靠词典猜汉字读法**，生僻人名必读错：

| 写法 | 词典会给 | 正确 |
|---|---|---|
| 豊川 | とよかわ | **とがわ** |
| 三角 | さんかく | **みすみ** |
| 馬橋 | まばし | **まはし** |
| 梅里 | うめさと | **うめざと** |

技能内含 25 人的**官方读法表**，做法是「只换写法、不换台词」：

```bash
node tools/vtool.mjs read                              # 打对照表（不需要语料包）
node tools/vtool.mjs read --in 台词稿.txt --out 台词稿_注音.txt
```

脚本只改「说话人：」之后的台词，单字名（燈/睦/律/凪/蛍/要/藤）只在左边不是汉字时才换，
所以 `必要`／`法律`／`要点` 不会被误伤。

## 数字是怎么来的（可自行复核）

每条实测都回答得了「多少次、出自哪一集」，口径写在 `references/07-取数说明.md`：

1. **称呼计数**：最长匹配优先、纯平假名写法要过边界、绰号与名字同级、自称不计入呼称；
2. **个人习惯挖掘**：不猜昵称构词法，改按「说话人集中度」反挖；再加一条「独用片假名串」通道，
   专抓 `ウミコ`／`ウイコ`／`ムーコ` 这类不含目标名字任何两字的叫法；
3. **文档自查**：`03c` 与 `03d` 里每个数字都与统计表逐项对账（73 项 + 105 项，零不一致）。

有语料包时，任何一条都能自己跑一遍：

```bash
node tools/vtool.mjs --pack <语料目录> self hotaru     # 该角色的语言指纹
node tools/vtool.mjs --pack <语料目录> call nyamu      # 她怎么称呼别人
```

## 没有语料也能用（三档降级）

| 档 | 环境 | 怎么做 |
|---|---|---|
| **A** | 只有对话窗 | 直接用 `02`–`05` 的对照表与实测数字；拿不准的说法在对话里问 |
| **B** | 能贴长文本 | 把相关那一集贴进来，让它找同类语尾的用法 |
| **C** | 有文件系统、能跑 Node | 用 `tools/vtool.mjs` 检索语料（`07` 说明语料格式） |

注音表与 `vtool read` 不需要语料包，装好技能即可用。

## 几点需要留意之处

- **只统计「说出口的称呼」**：日语大量场合直接省略称呼，省略同样正确；表里没有某一对，
  只说明原文没这么叫过，不等于这么叫是错的。
- **低频不等于错**：次数少说明原文里少用，作者要用是他的自由。
- **同一角色跨作品会变**：本技能的数字来自 Our Notes 一部作品，不要套到别的作品上。
- **台上代号是「演出来的那一版」语体**，不是另一个人格：切换到台上时自称、语尾、敬体、句长
  **四层一起换**，只换一个词是最容易读出来的破绽。
  另：若叶睦的 `mortis` 属 DID 人格，**不在本技能范围内**。
- **语言指纹一律取自日文原文**：中文译文会抹平自称、二人称、语尾与敬体，据译文反推语感会有偏差。
- 本技能**不含剧情原文，也不含官方中译**；`07` 里的数字口径可以脱离语料独立阅读。
